## Если что-то ломается

- Решение разошлось → шаг слишком велик; инварианты поедут первыми.
- Лампа рассыпается на KP-I → проверь знак σ и прогони `tools/residual.mjs`.
- Картинка забелена → карта цвета светлая в нуле, см. «Рендер».
- Пусто после пресета → координаты элемента пресета, см. «Ловушки».
- Переключатель GPU не переключается → `requestAdapter()` вернул `null`.
  В headless так быть НЕ должно; скорее всего кто-то добавил
  `--use-angle=swiftshader` в аргументы запуска, см. «Ловушки GPU».
- GPU медленнее, чем ожидалось → `npm run gpu-profile 1024 5`. Сравни ГБ/с
  каждого ядра с `copy` **из того же прогона**: если ядро сильно ниже — это
  оно, если все примерно на уровне `copy` — упёрлись в память и надо сокращать
  трафик, а не ядра. Разницу меньше напечатанного спреда игнорируй, а число
  выше `copy` считай сломанным замером, а не находкой.
- Мало шагов в секунду, но ядра в порядке → смотри не на ядра, а на дозировку
  кадра: потолок равен `шагов/кадр × fps`, см. «Дозировка кадра».
- Темп на GPU схлопнулся до 1 шага на кадр → измеритель времени. См.
  «Не мерь работу GPU настенными часами» в «Ловушках GPU».
- GPU-картинка чёрная, а инварианты живые → смотри на рендер, а не на солвер:
  бинд-группа рендера кеширована по id буфера, а буферы пересоздаются вместе с
  бэкендом (`gpuRenderer.invalidate()`).
- GPU считает не то → `npm run gpu-check`. Он сравнивает FFT, все 7 моделей и
  редукции с CPU на одной странице и печатает, где именно разошлось.
- Полная проверка снизу вверх:
  `node tools/residual.mjs` → `node tools/verify.mjs` →
  `node tools/smoke-browser.mjs shots` → `npm run gpu-check` →
  `node tools/smoke-browser.mjs shots gpu 512`.
  Смоук создаёт, применяет пресеты, спавнит и шагает все 7 моделей в реальном
  браузере и падает при любой ошибке в консоли.
